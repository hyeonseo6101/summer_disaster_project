**(1) 강우량**

사용 데이터

&#x09;- 서울시 강우량 정보 (10분 단위): 최근 3개년(2023년\~2025년) 여름철(6월\~8월) 강우 데이터

&#x09;- 서울시 강우량계 위치정보: 서울시 내 각 관측소의 공간(좌표 및 행정구역) 데이터

데이터 선정 이유

&#x09;- 최근 심화되는 '극한 강수' 트렌드를 기후 노출 지표에 반영하기 위하여

&#x09;- 도심 내수 침수를 유발하는 단시간 국지성 호우를 포착하기 위해 10분 단위로 나타난 데이터 활용



\### 1. 집중호우 지표 산출

\- 10분 단위 우량 -> 홍수에 직접 타격을 주는 극한 강수 지표로 리샘플링

&#x20;   - 일 최대 강수량 : 24시간동안 비가 가장 많이 내린 날의 강수량

&#x20;   - 시우량 : 1시간동안 내린 비의 양

&#x20;   - 총 강수량 : 해당 연도 여름동안 내린 전체 누적 강수량



\### 2. 위치 기반 매핑 및 자치구별 집계

\- 반지하비율(S1)과 맞춰 자치구별로 정리

&#x20;   - 데이터에 포함되어 있는 구청명 기준으로 groupby

&#x20;   - 해당 자치구 내 측정소들의 평균 또는 최댓값 (동일 구 안에 관측소 여러개)



\### 3. 취약성 평가 지수

\- 일 최대 강수량, 시간 최대 강수량을 정규화 후 평균 : 최종 E

&#x20;   - 홍수 취약성 공식에서 노출 지표(Exposure, E)



**(2) 반지하**

사용 데이터

&#x09;- 서울시 주택인허가 동별개요 데이터

데이터 선정 이유

&#x09;- 반지하 주택은 침수 피해에 가장 먼저 노출되는 취약 환경

&#x09;- 전체 주거용 건물 대비 반지하 비율을 산출해 그 지역의 취약 주거 환경 밀집도 평가하고자함

&#x09;- 건물의 주용도와 지하층수가 기록된 데이터를 활용해 실제 주거용 반지하만 추출하고자 함



\### 1. 기본 지표 추출 및 자치구 매핑

\- 자치구 단위로 가공

&#x20;   - 자치구명 추출

&#x20;   - 건물 수 집계 : 지하층수가 1 이상인 반지하 건물수와 전체 주거용 건물 수



\### 2. 반지하 비율 산출

\- 전체 주거 환경 대비 얼마나 밀집해있는지

&#x20;   - 비율 계산 : 반지하 건물 수 / 전체 주거용 건물 수



\### 3. 취약성 평가 지수

\- 정규화 과정 포함

&#x20;   - MIN-MAX 정규화 : 반지하 밀집도가 가장 높은 구는 1, 가장 낮은 구는 0

&#x20;   - S1 : 얼마나 위험에 노출되기 쉬운 상태인지 나타내는 민감도 지표 S1으로 사용



++ 법정동 -> 행정동으로 변환완료



**(3) 침수 흔적도**

\- 시각화 해보았으나 아주 일부 지역만 해당

\- 해당 데이터 및 전처리 파일 사용 X



**(4) 토지**

사용 데이터

&#x09;- 불투수면적 현황자료

데이터 선정 이유

&#x09;- 불투수면적은 빗물이 땅으로 흡수되지 못하게 하여 도심 내수 침수를 유발하는 가장 직접적인 환경 요인

&#x09;- 단순 강수량과 각 자치구의 실제 지표면 상태(구조적 민감도)를 결합해야 실제 표면유출량을 정확히 산출 가능



\### 1. 표면유출량(유효 강수량) 추정

\- 강수량과 불투수면적을 결합해 실제 도심 표면으로 흘러 넘치는 빗물의 양 산출

&#x20;   - 유효 최대 시우량

&#x20;       - 시간당 최대 강수량 \* 불투수면적 비율

&#x20;       - 단기간에 땅에 스며들지 못하는 빗물의 양

&#x20;   - 유효 최대 일강수량

&#x20;       - 일 최대 강수량 \* 불투수면적 비율

&#x20;       - 하루동안 침수 취약 구역에 지속적으로 누적되는 빗물의 양



\### 2. 위치 기반 데이터 결합

\- 기후 지표와 토지피복 지표를 동일한 기준으로 병합

&#x20;   - 자치구 기준으로 병합



\### 3. 표면 유출 위험지수 산출

\- 유효 시우량과 유효 일강수량을 각각 정규화 후 평균

&#x20;   - 최종 표면유출 위험지수



**(5) 하수도**

사용 데이터

&#x09;- 하수관거 현황 : 자치구별 하수관거 (전체 길이, 우수관거 길이 등)

&#x09;    - 하수도 및 부대시설 현황 : 자치구별 부대시설 (맨홀, 빗물받이 개수)



데이터 선정 이유

&#x09;- 도심 내수 침수를 일차적으로 방어하는 핵심 인프라인 지하 배수 시스템의 실질적인 수용 능력 평가

&#x09;- 하수관 길이 뿐만이 아니라 미세 배수 시설을 함께 고려하기 위해



\### 1. 하수도 인프라 방어 지표 산출

\- 빗물을 감당하는 관의 크기와 유입구의 수를 홍수 방어 지표로 연산

&#x20;   - 하수처리 용량(C\_gu) : 자치구별 하수관거 전체 길이와 우수관거(빗물관) 비율을 곱하여 산출한 절대적인 하수처리 용량

&#x20;   - 배수 인프라 밀도(MicroDrain\_Density) : 하수관거 1m 당 설치된 맨홀과 빗물받이의 총 개수



\### 2. 위치 기반 매핑 및 데이터 병합

\- 데이터에 포함된 자치구 기준으로 데이터 병합

\- 결측치 0으로 치환, 문자열->실수형으로 변환하는 정제 과정 수행



\### 3. 취약성 평가 지수

\- 인프라 용량과 밀도가 낮을수록 홍수에 위험하므로, 작을수록 1에 가까워지도록 역정규화 수행

&#x20;   - 하수처리 미흡 지표(S2) : 하수처리 용량 변환값, 1에 가까울수록 하수처리 부실

&#x20;   - 배수 취약성 지표(S3) : 배수 인프라 밀도 변환값, 1에 가까울수록 부족함을 의미



**(6) 하천수위**

\- 연도별로 다운 가능한 한강교가 다름

\- 특히나 반포2교는 최근 자료만 다운 가능

\- 사용할 시 최소한 각 구에 해당하는 한강교가 있어야 하나, 없는 구도 존재

\- 해당 데이터 및 전처리 파일 사용 X



**(7) 적응능력(AC) 관련 전처리**

사용 데이터

&#x09;- 서울시 빗물관리시설 통계 : 투수성 포장, 옥상녹화, 저류조 등 빗물을 일시적으로 가두거나 스며들게 하는 방어 시설 용량 데이터

&#x09;- 서울시 빗물펌프장 공간정보 : 도심에 고인 빗물을 하천으로 강제 배출하는 빗물펌프장 위치 및 개수 데이터



데이터 선정 이유

&#x09;- 동일한 양의 비가 오더라도, 자치구별 방어 인프라(빗물 저장 및 강제 배출 능력)가 잘 갖춰져 있다면 실제 피해가 줄어드므로, 취약성을 상쇄 시키는 적응 능력 변수로 반영하기 위함

&#x09;- 토지피복을 넘어 인공적으로 구축된 도싱ㅣ 실질적인 배수 및 저류 시스템 수용 역량 파악



\### 1. 빗물관리시설 방어력 지표 산출 (AC1)

\- 10분 단위 우량 폭증에 대비하여 하수관거의 부담을 덜어주는 인프라 용량 집계

&#x20;   - 저류 및 관리 용량 합산 : 자치구별 빗물관리시설의 빗물 관리량과 저류 용량 총합을 계산하여 1차 방어력 산출

&#x20;   - 결측치 : 비어있는 곳은 0으로 채움



\### 2. 위치 기반 매핑 및 펌프장 인프라 집계 (AC2)

\- 강제 배출을 통해 침수를 막아내는 인프라 밀집도 산출

&#x20;   - 펌프장 데이터 내 고유 관리코드를 추적하여 각 펌프장이 속한 자치구 매핑

&#x20;   - 자치구별 펌프장 개수 : 매핑된 자치구를 기준으로 펌프장의 총 개수 집계



\### 3. 취약성 평가 지수로의 통합

\- 산출된 시설 용량과 펌프장 개수를 정규화 후 평균하여 최종 AC 도출

&#x20;   - 홍수 취약성 공식 (V = E X S - AC)에서 위험을 상쇄시키는 지표로 활용
